# HYZ Mouse Hub

常驻 Windows 11 托盘的小工具：把无线外设的电量放到任务栏一眼可见，同时能读取、写入鼠标的板载 DPI，并把常用档位保存成多套配置随时切换。

## 功能

### 电量显示

- 两种托盘样式：**百分比数字**，或**设备图标式电量进度**（鼠标 / 键盘 / 耳机轮廓，电量自下而上填充）。
- 百分比模式下用图标底部的颜色条区分设备类型：蓝 = 鼠标、紫 = 键盘、品红 = 耳机。
- 电量按档位配色：红 ≤15%、橙 ≤40%、绿 >40%；充电时带黄色闪电标记。
- 低于设定阈值时弹出低电量提醒，阈值可自行调整。
- 启动后立即刷新一次，不必等下一个周期。

### 多设备同时显示

- 任务栏可以同时显示多台设备，每台一个独立图标，互不干扰。
- 可以只显示关心的设备，其余设备不占用托盘位置。
- 按住左键左右拖动图标即可调整前后顺序，松手即生效。
- 新插入的设备会自动纳入显示。

### 板载 DPI

- 读取鼠标当前上报的板载 DPI 与所在档位，直接显示真实值。
- 修改 X / Y 后写入鼠标板载存储，写完自动回读校验。
- 型号无法确认时只读不写，避免把设备配置写坏。

### 多套配置

- 把当前 DPI 保存成一条配置，随时在托盘右键一键应用。
- 支持重命名、删除、新建空白配置。
- 不会预置任何示例档位，列表里只有你自己保存过的配置。

### 耳机音量

- 识别 EPOS / GSA 70 播放端点，读取并直接调节系统音量。

### 界面

- 卡片式布局，每个模块独立成卡，内容完整显示，不裁切、不遮挡、不压缩控件。
- 窗口高度贴合内容，不浪费屏幕空间。
- 高分屏下文字清晰不发虚。

### 隐私

- 单文件绿色程序：无安装器、无后台服务、无遥测、不联网、不上传任何数据。
- 只在系统启动项中写入一条记录，且仅在你勾选「开机自动启动」后写入。
- 所有配置都保存在本机 `%AppData%\HYZMouseHub`。

## 下载

到 [Releases](https://github.com/rogergzl/HYZMouseHub/releases) 页面下载最新的 `HYZMouseHub.exe`，双击即可运行，免安装、无需管理员权限。

仓库只存放源码，不放编译产物；想自己构建见 `build.cmd`（需要 .NET SDK）。

## 使用

1. 双击 `HYZMouseHub.exe`，弹出主界面，托盘出现设备电量图标。
2. 左键点托盘图标打开主界面，右键是快捷菜单（电量、显示样式、刷新间隔、配置档位、开机自启）。
3. 在「设备状态」里选择设备，点「读取硬件 DPI」，改完点「写入板载 DPI」。
4. 顺手点「保存当前为配置」，以后在托盘右键就能一键切回来。
5. 在「托盘显示设备」里勾选要在任务栏显示的设备。
6. 需要开机就在托盘待命，勾选「开机自动启动」——开机那次不弹窗，手动双击仍会弹出主界面。

## 系统要求

- Windows 10 1809 及以上 / Windows 11，64 位。
- 无需安装运行时，系统自带 .NET Framework 4.8 即可。

## 说明与限制

- **电池健康度**（容量衰减、循环次数）这些外设都不对外提供，程序不会显示编造的健康百分比；ATK 会额外显示设备上报的瞬时电压。
- 设备深度休眠时读不到电量，会显示为离线并保留上一次的数值，动一下设备即可恢复。
- 原厂驱动（如雷蛇 Synapse）占用设备接口时可能读取或写入失败，退出原厂软件后重试。
- Windows 11 默认会把多个托盘图标折叠进 `^`，展开小箭头即可看到全部。
- 百分比数字为透明背景深色文字，若系统托盘为深色主题看不清，可切换成图标样式。
- 非官方工具，与各品牌厂商无关。
